# Шкала коморбидности Чарлсона

Индекс предсказывает 10-летнюю выживаемость пациента с учётом сопутствующих
заболеваний и возраста. Каждое состояние имеет вес 1, 2, 3 или 6 баллов;
за каждую декаду после 50 лет добавляется 1 балл.

### Баллы

| Вес | Состояния |
|-----|-----------|
| **1** | Инфаркт миокарда, сердечная недостаточность, заболевания периферических артерий, ОНМК/ТИА, деменция, хронические болезни лёгких, болезни соединительной ткани, язвенная болезнь, заболевание печени без портальной гипертензии, сахарный диабет без поражения органов |
| **2** | Гемиплегия, умеренная или тяжёлая болезнь почек, диабет с поражением органов-мишеней, солидная опухоль, лейкоз, лимфома |
| **3** | Заболевание печени с портальной гипертензией |
| **6** | Метастатическая опухоль, СПИД |

### Возраст

| Возраст | Баллы |
|---------|-------|
| < 50 лет | 0 |
| 50–59 лет | +1 |
| 60–69 лет | +2 |
| 70–79 лет | +3 |
| ≥ 80 лет | +4 |

### Интерпретация

| Индекс | 10-летняя выживаемость |
|--------|------------------------|
| 0 | 99 % |
| 1 | 96 % |
| 2 | 90 % |
| 3 | 77 % |
| 4 | 53 % |
| 5 | 21 % |
| ≥ 6 | 2 % |
