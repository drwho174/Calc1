# Glomerular filtration rate

This calculator estimates the **glomerular filtration rate** using the CKD-EPI 2021 creatinine equation.

Formula:

$$
GFR = 142 * (Scr/A)^{B} * 0,9938^{age} * (1,012< if female>)
$$

Where:

| Female    |                        | Male      |                        |
|-----------|------------------------|-----------|------------------------|
| Scr ≤ 0,7 | A = 0.7<br> B = -0.241 | Scr ≤ 0,9 | A = 0.9<br> B = -0.302 |
| Scr > 0,7 | A = 0.7<br> B = -1.2   | Scr > 0,9 | A = 0.9<br> B = -1.2   |
