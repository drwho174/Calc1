# Mehran Score

This score predicts contrast-induced nephropathy after
percutaneous coronary intervention.

### Calculation

Score table:

| Parameter                                          |            | Points                     |
|----------------------------------------------------|------------|----------------------------|
| Hypotension*                                       | No         | 0                          |
|                                                    | **Yes**    | **5**                      |
| Intra-aortic balloon counterpulsation (IABP)       | No         | 0                          |
|                                                    | **Yes**    | **5**                      |
| Congestive heart failure**                         | No         | 0                          |
|                                                    | **Yes**    | **5**                      |
| Age >75 years                                      | No         | 0                          |
|                                                    | **Yes**    | **4**                      |
| Anaemia***                                         | No         | 0                          |
|                                                    | **Yes**    | **3**                      |
| Diabetes mellitus                                  | No         | 0                          |
|                                                    | **Yes**    | **3**                      |
| Contrast volume                                    | -          | 1 point per 100 mL of contrast |
| GFR, mL/min/1.73 m2                                | ≥60        | 0                          |
|                                                    | 40 to <60  | 2                          |
|                                                    | 20 to <40  | 4                          |
|                                                    | <20        | 6                          |

*Systolic blood pressure <80 mmHg for 1 hour requiring periprocedural inotropic support or IABP within 24 hours.

**NYHA class III/IV and/or a history of pulmonary oedema.

***Mean haematocrit <39% for men and <36% for women.

Note: the original study includes serum creatinine (as a dichotomous variable)
as an alternative to GFR and adds 4 points for Cr >1.5 mg/dL.
We decided (the authors of the original calculator — _ed._) to use eGFR in this calculator,
because it is generally a more accurate measure of renal function than creatinine alone.

### Interpretation

| Score        | Risk of post-PCI CIN |                           |
|--------------|----------------------|---------------------------|
|              | **Any CIN**          | **CIN requiring dialysis** |
| ≤5           | 7.5%                 | 0.04%                     |
| 6-10         | 14.0%                | 0.12%                     |
| 11-15        | 26.1%                | 1.09%                     |
| ≥16          | 57.3%                | 12.6%                     |
