# ARISCAT

Индекс предсказывает риск послеоперационных лёгочных осложнений (пневмония,
дыхательная недостаточность, ателектаз, бронхоспазм, плевральный выпот,
пневмоторакс, аспирационный пневмонит) после некардиохирургических операций.

### Критерии

| Фактор | Баллы |
|---|---|
| Возраст | ≤ 50 лет — 0; 51–80 лет — 3; > 80 лет — 16 |
| SpO2 до операции | ≥ 96 % — 0; 91–95 % — 8; ≤ 90 % — 24 |
| Респираторная инфекция за последний месяц | 17 |
| Анемия (Hb ≤ 10 г/дл) | 11 |
| Доступ | периферический — 0; верхняя лапаротомия — 15; торакотомия — 24 |
| Длительность операции | < 2 ч — 0; 2–3 ч — 16; > 3 ч — 23 |
| Экстренная операция | 8 |

### Интерпретация

| Сумма баллов | Риск |
|---|---|
| < 26 | Низкий |
| 26–44 | Средний |
| ≥ 45 | Высокий |

При среднем и высоком риске обсуждаются периоперационная респираторная
поддержка, ранняя активизация, дыхательная гимнастика и отказ от
длительной иммобилизации.
