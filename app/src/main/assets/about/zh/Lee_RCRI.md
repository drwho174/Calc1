# Lee 指数（修订心脏风险指数，RCRI）

用于评估非心脏手术中主要心脏并发症（MACE：心源性死亡、心肌梗死、心脏骤停）的风险。
包含六项独立预测因素，总分 0–6 分。

### 指标

| 预测因素 | 分值 |
|---|---|
| 高风险手术（胸内、腹内或腹股沟韧带以上的血管手术） | 1 |
| 缺血性心脏病 | 1 |
| 心力衰竭 | 1 |
| 有脑卒中或 TIA 史 | 1 |
| 需要胰岛素治疗的糖尿病 | 1 |
| 肌酐 > 177 µmol/L（2 mg/dL） | 1 |

### 结果解读

| 总分 | MACE 风险 |
|---|---|
| 0 | 0.4 % |
| 1 | 0.9 % |
| 2 | 7 % |
| ≥ 3 | 11 % |

上述数值来自原始研究的验证队列。评分为 2 分及以上时，
应考虑进一步的心脏评估和围手术期监测。
