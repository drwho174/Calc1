# ARISCAT

该指数预测非心脏手术后肺部并发症（肺炎、呼吸衰竭、肺不张、支气管痉挛、
胸腔积液、气胸、吸入性肺炎）的风险。

### 指标

| 因素 | 分值 |
|---|---|
| 年龄 | ≤ 50 岁 — 0；51–80 岁 — 3；> 80 岁 — 16 |
| 术前 SpO2 | ≥ 96 % — 0；91–95 % — 8；≤ 90 % — 24 |
| 近一个月内的呼吸道感染 | 17 |
| 贫血（Hb ≤ 10 g/dL） | 11 |
| 切口 | 外周 — 0；上腹正中切口 — 15；开胸 — 24 |
| 手术时长 | < 2 小时 — 0；2–3 小时 — 16；> 3 小时 — 23 |
| 急诊手术 | 8 |

### 结果解读

| 总分 | 风险 |
|---|---|
| < 26 | 低 |
| 26–44 | 中 |
| ≥ 45 | 高 |

中、高风险时应考虑围手术期呼吸支持、早期活动、呼吸功能锻炼，
并避免长时间制动。
