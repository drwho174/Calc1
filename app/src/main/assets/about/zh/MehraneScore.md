# Mehran 评分

该评分用于预测经皮冠状动脉介入治疗（PCI）后
对比剂肾病的发生风险。

### 计算

评分表：

| 参数                                        |            | 分值                          |
|---------------------------------------------|------------|-------------------------------|
| 低血压*                                     | 否         | 0                             |
|                                             | **是**     | **5**                         |
| 主动脉内球囊反搏（IABP）                    | 否         | 0                             |
|                                             | **是**     | **5**                         |
| 充血性心力衰竭**                            | 否         | 0                             |
|                                             | **是**     | **5**                         |
| 年龄 >75 岁                                 | 否         | 0                             |
|                                             | **是**     | **4**                         |
| 贫血***                                     | 否         | 0                             |
|                                             | **是**     | **3**                         |
| 糖尿病                                      | 否         | 0                             |
|                                             | **是**     | **3**                         |
| 造影剂用量                                  | -          | 每 100 mL 造影剂 1 分         |
| 肾小球滤过率，mL/min/1.73 m2                | ≥60        | 0                             |
|                                             | 40 至 <60  | 2                             |
|                                             | 20 至 <40  | 4                             |
|                                             | <20        | 6                             |

*收缩压 <80 mmHg 持续 1 小时，需要围手术期正性肌力药物支持，
或在 24 小时内使用 IABP。

**NYHA III/IV 级和/或既往有肺水肿病史。

***平均红细胞压积：男性 <39%，女性 <36%。

注：原始研究将血清肌酐（作为二分类变量）作为肾小球滤过率的替代指标，
并对 Cr >1,5 mg/dL 加 4 分。
我们认为（原计算器作者——_编者注_）本计算器应采用 eGFR，
因为它通常比单一肌酐更能准确反映肾功能。

### 结果解读

| 总分 | PCI 术后 CIN 风险   |                           |
|------|---------------------|---------------------------|
|      | **任何 CIN**        | **需透析的 CIN**          |
| ≤5   | 7.5%                | 0.04%                     |
| 6-10 | 14.0%               | 0.12%                     |
| 11-15| 26.1%               | 1.09%                     |
| ≥16  | 57.3%               | 12.6%                     |
