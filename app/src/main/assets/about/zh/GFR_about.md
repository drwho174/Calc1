# 肾小球滤过率

本计算器根据血肌酐浓度，采用 CKD-EPI 2021 公式计算**肾小球滤过率**。

公式：

$$
GFR = 142 * (Scr/A)^{B} * 0,9938^{age} * (1,012< if female>)
$$

其中：

| 女性      |                        | 男性      |                        |
|-----------|------------------------|-----------|------------------------|
| Scr ≤ 0,7 | A = 0.7<br> B = -0.241 | Scr ≤ 0,9 | A = 0.9<br> B = -0.302 |
| Scr > 0,7 | A = 0.7<br> B = -1.2   | Scr > 0,9 | A = 0.9<br> B = -1.2   |
