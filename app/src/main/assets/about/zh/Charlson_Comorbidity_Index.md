# Charlson 合并症指数

该指数结合合并症与年龄预测 10 年生存率。每种疾病的权重为 1、2、3 或 6 分；
50 岁以后每 10 年加 1 分。

### 分值

| 权重 | 疾病 |
|-----|-----------|
| **1** | 心肌梗死、心力衰竭、外周动脉疾病、脑卒中/TIA、痴呆、慢性肺疾病、结缔组织病、消化性溃疡病、无门静脉高压的肝病、无靶器官损害的糖尿病 |
| **2** | 偏瘫、中度或重度肾病、伴靶器官损害的糖尿病、实体瘤、白血病、淋巴瘤 |
| **3** | 伴门静脉高压的肝病 |
| **6** | 转移性肿瘤、艾滋病 |

### 年龄

| 年龄 | 分值 |
|---------|-------|
| < 50 岁 | 0 |
| 50–59 岁 | +1 |
| 60–69 岁 | +2 |
| 70–79 岁 | +3 |
| ≥ 80 岁 | +4 |

### 结果解读

| 指数 | 10 年生存率 |
|--------|------------------------|
| 0 | 99 % |
| 1 | 96 % |
| 2 | 90 % |
| 3 | 77 % |
| 4 | 53 % |
| 5 | 21 % |
| ≥ 6 | 2 % |
