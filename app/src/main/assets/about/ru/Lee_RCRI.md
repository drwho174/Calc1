# Индекс Lee (Revised Cardiac Risk Index, RCRI)

Оценивает риск крупных кардиальных осложнений (MACE: сердечная смерть,
инфаркт миокарда, остановка сердца) при внесердечных операциях.
Шесть независимых предикторов, сумма 0–6.

### Критерии

| Предиктор | Баллы |
|---|---|
| Высокорисковая операция (внутригрудная, внутрибрюшная, сосудистая выше паховой связки) | 1 |
| Ишемическая болезнь сердца | 1 |
| Сердечная недостаточность | 1 |
| ОНМК или ТИА в анамнезе | 1 |
| Сахарный диабет, требующий инсулина | 1 |
| Креатинин > 177 мкмоль/л (2 мг/дл) | 1 |

### Интерпретация

| Сумма | Риск MACE |
|---|---|
| 0 | 0,4 % |
| 1 | 0,9 % |
| 2 | 7 % |
| ≥ 3 | 11 % |

Значения соответствуют валидационной когорте оригинального исследования.
При риске 2 балла и выше обсуждаются дополнительное кардиологическое
обследование и периоперационный мониторинг.
